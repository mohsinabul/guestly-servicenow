# About these captures

All 20 images are original screenshots supplied by the project owner on 15 November 2026. Their pixels and dimensions are preserved. Captions highlight features without changing what the application shows.

Some long lists end below the captured area. These images document the visible view, rather than every record in the system. Bookings, rooms and feedback have pagination where shown.

The captures include known sample-data issues: a room reference appears as a raw ID in booking BKG0001122; some dates and prices are blank; guest greetings and the header identity differ in several guest views. These are retained in the originals. They should be checked before treating this as a release-ready application.

Static screenshots show interface states. The recorded walkthrough is separate evidence of interactions. The screenshots alone do not prove access-control enforcement, email delivery or sentiment accuracy.

This repository is a visual case study. It does not contain an installable application, credentials, exported user tables or automated test results. No production outcomes are claimed.
